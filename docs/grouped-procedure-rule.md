# Правило объединения групповых процедур

Несколько назначенных процедур представляют одну логическую групповую
процедуру только при совпадении всех четырёх полей:

- день (`dayId`);
- время начала (`startTime`);
- вид процедуры (`procedureKindId`);
- ведущий / сопровождающий (`assistantId`).

Правило используется для списка участников, представления расписания ведущего
и расчёта конфликтов. Если отличается хотя бы одно поле, это разные логические
процедуры; в частности, разные виды процедур у одного ведущего в одно время
не объединяются и конфликтуют.
